Files:

- assets/: original screenshots extracted from the user-provided PDF

Preview:
Double-click index.html or open it in a browser.

Public hosting with GitHub Pages:
1. Sign in to GitHub and create a new public repository.
2. Upload index.html and the entire assets folder (keep folder/file names unchanged).
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and / (root), then Save.
5. Wait for the Pages URL to appear in Settings > Pages.

Important:
The website uses Oracle VirtualBox, Kali Linux, and Windows tutorials. Original screenshots from the supplied PDF are preserved and included in the relevant steps and gallery.
